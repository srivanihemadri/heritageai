## Acquisition Policy

1. Verify the source page immediately before acquisition.
2. Download the original file rather than a third-party re-upload.
3. Preserve the source-page URL in this manifest.
4. Do not register a media record until the downloaded file has been verified locally.
5. Verify the final `/media/...` URL returns HTTP 200.
